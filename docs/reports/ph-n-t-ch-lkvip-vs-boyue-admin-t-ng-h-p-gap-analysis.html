Phân tích đầy đủ trang quản trị Boyue (PHP/Webman/Layui) tại /var/www/boyue và LKVIP Admin Dashboard (React 18 / Ant Design / Node.js) tại /var/LKVIP/code — những gì đã có, những gì cần bổ sung.

1. Kiến trúc so sánh

🟡 Boyue (nguồn học hỏi)

  • PHP 8 / Webman framework
  • Frontend: Vue 3 + Element Plus (Art Design Pro) + Layui demo pages
  • Backend: Raw Db:: query builder, không ORM
  • Admin route: /app/admin/*
  • Auth: JWT (JwtService.php)
  • 5 admin controllers: Activity, ActivityReward, GameManage, GameCategory, IM
  • DB: MySQL 1 schema duy nhất (bảng caipiao_*, api_game_configs)
  • WebSocket: AdminWebSocketPusher.php
  • Anti-cheat: AntiCheatService.php
  • Menu: dynamic từ /app/admin/rule/get
  • Theme: dark/light, 5 màu, tab multi-page

🔵 LKVIP (dự án của mình)

  • Node.js 20 / Express / TypeScript
  • Frontend: React 18 + Ant Design 5 + Tailwind
  • Backend: Prisma ORM, 6 databases riêng
  • Admin route: /api/admin/*
  • Auth: JWT + refresh token, adminGuard middleware
  • 30+ admin controllers (dashboard, finance, users, risk, ops…)
  • DB: 6 schemas (hub/game/dating/trade/sports/admin)
  • WebSocket: useAdminSocket.ts, Socket.IO
  • Risk Engine: RFM, AML, brute-force, IP blacklist
  • Module registry: plug-and-play per sub-project
  • BullMQ queues, Redis cache, cron jobs

2. Boyue có gì — LKVIP học được gì

2.1 Game Management (GameManageController.php)

Boyue quản lý game qua bảng api_game_configs (TCG) LEFT JOIN caipiao_game. Filter: vendor, gameType (RNG/LIVE/FISH/SPORTS/ESPORTS/PVP/ELOTTO/COCKFIGHT), status, gameName. Endpoint POST /admin/game/status cập nhật đồng thời 2 bảng + batch status.

✓ LKVIP có: GameProvidersPage + /admin/game/providers ⚠ LKVIP thiếu: gameType filter RNG/LIVE/FISH/COCKFIGHT ⚠ LKVIP thiếu: batch toggle status nhiều game cùng lúc ⚠ LKVIP thiếu: LEFT JOIN sync 2 bảng game khi toggle

2.2 Activity & Promotion System (ActivityCategoryController + ActivityRewardController)

Boyue có hệ thống khuyến mãi 3 lớp: Category → Activity (huodong) → Reward. Mỗi reward có: rewardType, conditionMin/Max, rewardAmount, rewardRate, limitTimes, limitPeriod, needApply. Sort + enable/disable riêng.

✓ LKVIP có: PromotionPage với WELCOME/DEPOSIT/CASHBACK/FREE_SPIN/REFERRAL/EVENT/VIP ⚠ LKVIP thiếu: Category phân cấp (Category → Activity → Reward) ⚠ LKVIP thiếu: limitPeriod (daily/weekly/monthly), needApply flag ⚠ LKVIP thiếu: wagering requirement per reward tier

2.3 Dashboard Console (console1.html / console2.html)

Boyue dùng Layui + SVG icons cho: 今日访问 (daily visits), 提交次数 (submissions), 下载数量 (downloads), 消息总数 (messages). Đây là style dashboard đẹp với panel cards + ECharts.

✓ LKVIP có: Dashboard.jsx với KPI cards, revenue chart SVG, project bars ⚠ LKVIP thiếu: Lượt truy cập hôm nay, số lượng đăng ký mới ⚠ LKVIP thiếu: Biểu đồ ECharts-style cho active users realtime

2.4 Role & Permission System (role.html + permission.js)

Boyue có RBAC với menu /app/admin/rule/get dynamic. Role CRUD, assign permission tree, user role assignment. Switch enable/disable per role.

✓ LKVIP có: AdminUserManagement + registry.ts với minRole, projectId gate ⚠ LKVIP thiếu: Role CRUD UI (tạo/sửa/xóa role từ giao diện) ⚠ LKVIP thiếu: Permission tree assign per role 🆕 Cần thêm: RolesPage.jsx + /admin/roles endpoint

2.5 Anti-Cheat & IM (AntiCheatService + IMService + ImController)

Boyue có AntiCheatService.php phát hiện gian lận. IMService.php + ImController admin cho chat trong game. AdminWebSocketPusher push realtime cho admin.

✓ LKVIP có: RiskAudit.jsx với 7 tabs + SecurityLogs + IP Blacklist ✓ LKVIP có: useAdminSocket + RealtimePage ⚠ LKVIP thiếu: IM/Chat admin panel (xem/gửi tin nhắn game chat) 🆕 Cần thêm: AdminIMPage.jsx + /admin/im endpoint

4. Kế hoạch cập nhật — Ưu tiên

  • 🔴 P1 — Batch Game Status toggle
    Backend: POST /admin/game/batch-status trong gameConfigController.ts. Frontend: checkbox trong GameRoundsPage + xác nhận modal.
  • 🔴 P1 — Role Management UI
    Tạo RolesPage.jsx + /admin/roles CRUD endpoint. Hiện tại adminGuard chỉ check role từ JWT, chưa có giao diện tạo/sửa role.
  • 🔴 P1 — Rebate Management
    Boyue có RebateService.php + RebateController.php đầy đủ. LKVIP chưa có module hoàn trả (rebate). Cần: Prisma model + controller + RebatePage.jsx.
  • 🟠 P2 — GameType Filter (RNG/LIVE/FISH/COCKFIGHT)
    Boyue map gameCategory → gameType (8 loại). Thêm Select filter vào GameRoundsPage.jsx + truyền gameType query param.
  • 🟠 P2 — Promotion Reward Tiers
    Boyue có 3 lớp Category→Activity→Reward với limitPeriod, needApply. Mở rộng PromotionPage.jsx + thêm bảng PromotionReward vào admin Prisma schema.
  • 🟠 P2 — IM / Chat Admin Panel
    Boyue ImController cho admin quản lý tin nhắn game. Thêm AdminIMPage.jsx (tabs: conversations, broadcast message, mute user) + /admin/im endpoints.
  • 🟠 P2 — Dashboard: Lượt truy cập hôm nay + Đăng ký mới
    Thêm 2 KPI card vào Dashboard.jsx: todayVisits (từ Redis session count) và newSignups (đã có trong dashboardController nhưng chưa hiển thị đủ).
  • 🔵 P3 — K3 / XY28 Lottery specific tabs
    Boyue có K3Controller và XY28Controller riêng. Thêm tab K3/XY28 vào GameLotteryPage.jsx nếu dự án dùng các game số này.
  • 🔵 P3 — Collector / Payment Proxy
    Boyue có CollectorService.php thu nạp từ proxy. Nếu LKVIP cần payment proxy, thêm vào shared/payment/ layer.
  • 🔵 P3 — Yuebao (Savings/Investment)
    Boyue YuebaoService.php = tiết kiệm có lãi suất. Có thể map sang trade/investments của LKVIP — TradeInvestmentsPage.jsx đã có.

✅ Kết luận

LKVIP Admin Dashboard đã vượt trội Boyue trên các mặt: kiến trúc multi-project, OPS automation, AML/Risk engine, Security settings, BullMQ queue.
Boyue cung cấp 3 tính năng LKVIP chưa có và cần học hỏi ngay: (1) Batch Game Status, (2) Role/Permission CRUD UI, (3) Rebate Management.
Các tính năng còn lại (IM panel, Promotion Tiers, GameType filter) có thể triển khai theo sprint tiếp theo.
