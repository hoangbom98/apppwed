  • User — roles: user | admin; kycStatus; status
  • Market — code unique (CRYPTO, FOREX, …)
  • Symbol → Market; leverage config; tick/step size
  • PriceHistory — OHLCV candles per interval
  • Order — side, type, status lifecycle
  • Position — long/short, PnL, margin, closedAt

Finance Models

  • Wallet — userId UNIQUE; balance + frozen

Auth & Middleware Stack

JWT Payload

  • id, email, role, project
  • Access token: JWT_SECRET (2h default)
  • Refresh token: JWT_REFRESH_SECRET (30d)

Per-route Protection

  • User routes: auth → projectAccessGuard
  • Admin routes: auth → adminGuard
  • Public routes: no middleware

Global Middleware Pipeline

  • helmet, cors, json/urlencoded body parsers
  • morgan (access log), i18next, publicLimiter
  • ddosGuard, ipBlockGuard, injectionGuard, botGuard
  • projectResolver → sets req.project + req.prisma
  • configResolver → sets req.configService

Project Resolution (priority)

  • 1. URL path prefix (/api/trade/* → trade)
  • 2. Hostname subdomain (trade.domain.com)
  • 3. X-Project header

Known Gaps & TODOs

Not yet implemented / stubbed:
  • SMS: SMS_PROVIDER=console — Twilio wired but untested
  • AI Services: ENABLE_AI=false — DeepSeek/OpenAI optional keys
  • WebRTC TURN server: env vars present, server not deployed
  • FCM Push: firebase-service-account.json not committed — admin notification controller gracefully stubs if missing
  • JWT project field check: projectAccessGuard validates user in DB but does not yet enforce req.user.project === req.project
  • CORS production guard: missing CORS_ORIGINS falls back to true (allow all) — should throw in production
  • Price feed: ENABLE_PRICE_FEED=false — CoinGecko/Alpha Vantage not live
  • walletController.approveDeposit / rejectDeposit: legacy methods operating on Transaction model (stale; real deposit flow uses depositController)
