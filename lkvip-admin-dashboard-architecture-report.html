🔐 Auth & State Flow

Zustand Store — adminStore.js (persisted)

State: user, token, isLoading

Actions: login(credentials) → POST /admin/auth/login → saves token to localStorage key admin_token → navigates to /

Actions: logout() → clears token → navigates to /login

Persistence: zustand/middleware persist — partializes { user, token } only

API Client — api/client.js (Axios instance)

Base URL: VITE_API_URL (default: http://localhost:5000/api)

Request interceptor: attaches Authorization: Bearer {token} from admin_token

Response interceptor: on 401 → clears token + redirect /login

NOTE: No X-Project header in API client — admin routes use adminGuard (role-only) not projectAccessGuard
