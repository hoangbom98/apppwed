6. Insights Kỹ Thuật Học Được

Pattern: Optimistic Lock cho Wallet Balance

Legacy accounts table dùng version INT để tránh race condition khi nhiều worker credit/debit cùng lúc. LKVIP dùng Prisma $transaction nhưng chưa có version field. Nên thêm version Int @default(0) vào Wallet model + implement optimistic lock check.

Pattern: trano (Transaction Reference Number)

Legacy tạo trano theo format: {RANDOM_CHAR}{YYMMDD}{SEQ}{UID} — ví dụ M25112506085594577. LKVIP cần đảm bảo referenceId có format tương tự để match webhook từ payment gateway.

Pattern: Rebate Tier Config

Legacy có rebate rate riêng biệt theo game type (live/fish/slot/lottery/sport/chess/esport) PER VIP level. LKVIP hiện dùng RebateRule generic. Cần extend để hỗ trợ per-game-type rates nếu muốn feature parity.

CDN Image URL Pattern (TCG)

Game icon: https://images.b728484.com:42666/TCG_GAME_ICONS/{PLATFORM}/VI/{game_id}.png
Platform banner: https://images.b728484.com:42666/TCG_PROD_IMAGES/VENDOR/WEB/BASE/NAV/{TYPE}_{PLATFORM}.png
Local path backup: /game_pictures/p/280/L1/{product_type}/{game_type}/custom_VND.avif

Blockchain Password Migration

File migrate_password_schema.sql cho thấy blockchain platform dùng lc_user và system_user với password VARCHAR(60) cũ (MD5). Migration mở rộng lên VARCHAR(255) để hỗ trợ bcrypt. LKVIP đã dùng bcrypt ngay từ đầu — không cần migration này.

Domain & Config Production

Domain production từ 004_settings_vn.sql: boyue.okwink6.com (legacy). LKVIP đã cập nhật sang tc-gaming.live. Settings VN: min_recharge=100K, max_recharge=500M, tikuanMin=200K, tikuanMax=50M, giờ rút 00:10–23:55, số lần rút 10 lần/ngày.

Activity System Logic

Legacy có 3 loại activity chính: (1) lucky_order — thưởng khi đuôi mã cược khớp (888/8888/88888), (2) loss_rescue — cứu trợ theo tổng thua lỗ hàng ngày theo bậc, (3) weekly_salary — lương theo tổng cược tuần theo bậc. Đây là promotions động, cần ActivityReward table với tiered config.
