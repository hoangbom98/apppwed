3. Game Provider — TCG (OKWINK6) vs GSC+ (LKVIP)

TC-Gaming (OKWINK6)

  • Endpoint: connect6play.com/doBusiness.do
  • Mã hóa: DES-ECB + SHA256
  • Merchant: ewiinvndk
  • Prefix user: 14b + username (max 14 ký tự)
  • Currency: VNDK (1 VNDK = 1000 VND)
  • Inbound callback: /api/tcg/wallet/*
  • Sync bets worker: mỗi 30s
  • Product IDs: 2 (Lottery), 7 (RNG), 6 (Live), 151 (Sport)...

GSC+ Seamless (LKVIP)

  • API v2.0.6, HMAC-SHA256
  • GscPlusGameLaunchService → aggregator layer
  • Platform mapping: GameCategoryMapping.ts
  • Categories: SLOT, LIVE_CASINO, FISHING, TABLE_GAME, SPORTSBOOK...
  • Inbound callback: /game/v1/api/seamless/{action}
  • Goldgate provider cũng hỗ trợ song song
  • TC-Gaming callback tại /game/callbacks/tc-gaming/seamless
  • Có thể dùng cả 2 TCG + GSC+ đồng thời!
💡 Cơ hội tích hợp TCG vào LKVIP Game: Boyue đã có TcgService.php với full protocol DES+SHA256. LKVIP backend đã có providerCallbackController với route /callbacks/tc-gaming/seamless nhưng chưa có service TcGamingProvider tương đương — cần port logic từ /var/www/boyue/app/service/TcgService.php.

5. Gap Analysis — Những gì LKVIP Game còn thiếu

🔴 Quan trọng — cần làm ngay:
  1. Yuebao API thiếu: yuebao.ts gọi /yuebao/products, /yuebao/my, /yuebao/invest nhưng backend chưa có route. Cần thêm yuebaoController + route + Prisma models YuebaoProduct, YuebaoHolding.
  2. Rebate API: rebate.ts gọi /game/rebate/status, /game/rebate/claim, /game/rebate/history, /game/rebate/rates — backend chưa có controller cho rebate trong module game.
  3. TCG Provider Service: tc-gaming/ thư mục tồn tại nhưng thiếu implementation đầy đủ theo protocol DES+SHA256 như TcgService.php.
🟡 Nên làm — cải thiện:
  1. Yuebao views/Yuebao.tsx đang gọi đúng API nhưng endpoint backend chưa match — cần sync route path.
  2. Rebate views/Rebate.tsx đang có UI hoàn chỉnh, cần backend route /game/rebate/*.
  3. Mining.tsx + DailyMissions.tsx + Checkin.tsx — học từ OKWINK6's YuebaoInterest + ScheduledTasks pattern.
  4. WebSocket realtime balance: WAP dùng wss://boyue.okwink6.com/ws. LKVIP useSocket.ts cần connect đúng WS endpoint.

6. Middleware Stack So sánh

OKWINK6 — config/middleware.php

  1. ExceptionMiddleware — catch global
  2. CorsMiddleware — CORS headers
  3. RateLimitMiddleware — Redis rate limit
  4. EncryptionMiddleware — AES decrypt req / encrypt resp
  5. AuthMiddleware — JWT (protected routes only)

⚠️ TCG callbacks BỎ QUA cả AES lẫn JWT!

LKVIP Game — routes/index.ts

  1. auth middleware — JWT verify
  2. adminGuard — role check
  3. auditLogger — mutation logging
  4. httpCache(ttl) — HTTP cache headers

GSC seamless callbacks không dùng auth — verify bằng HMAC signature.

9. Kế hoạch Hành động — Ưu tiên

🔵 Sprint 1 — Backend Routes thiếu (1–2 ngày):
  1. Thêm Yuebao module: yuebaoController.ts + routes /game/yuebao/* + Prisma models YuebaoProduct, YuebaoHolding
  2. Thêm Rebate module: rebateController.ts + routes /game/rebate/* — học từ RebateService.php
  3. Thêm Mining module: routes /game/mining/* cho Mining.tsx
🟢 Sprint 2 — Hoàn thiện TCG Provider (2–3 ngày):
  1. Port TcgService.php → TcGamingProvider.ts dùng DES-ECB + SHA256
  2. Tạo Prisma migration: TcgWalletTransaction, TcgWalletReserve
  3. Hoàn thiện providerCallbackController.tcGamingSeamless()
  4. Test end-to-end: createPlayer → launchGame → debit/credit callbacks
🟣 Sprint 3 — Realtime & Workers (3–4 ngày):
  1. WebSocket balance push: học từ WebSocketPusher::pushToUser() của WAP
  2. BullMQ CRON: sync bet history (như TcgBetSyncWorker mỗi 30s)
  3. BullMQ CRON: daily Yuebao interest (như YuebaoInterest.php lúc 00:05)
  4. Agent commission trigger khi bet settled
