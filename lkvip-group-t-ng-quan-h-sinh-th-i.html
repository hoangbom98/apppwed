6. Luồng Dữ Liệu Quan Trọng
Auth Flow
[Frontend] → POST /api/auth/login → authenticate middleware (JWT HTTP-only cookie) → projectAccessGuard (lấy projectKey từ subdomain/header) → rateLimiter → AuthController → AuthService.login(username, password, ip, ua) → admin_db.User lookup → bcrypt compare → JWT (access 15m + refresh 7d) → Redis session → Set HTTP-only cookie → { success: true, data: TokenPair }
Wallet Credit/Debit Flow
WalletService.credit(userId, amount, walletType, description) → decimal.js arithmetic (KHÔNG dùng Number/BigInt) → Prisma $transaction { UPDATE Wallet WHERE id=$id AND version=$old (optimistic lock) INSERT Transaction (immutable ledger) } → NotificationService.send() → Socket.IO emit (realtime)
BullMQ Job Flow
Cron / Event → Queue.add(jobName, payload) → BullMQ Worker picks up → Process: lottery-settlement | rebate | agent-commission | interest-payout… → WalletService.credit() for winners → NotificationService.send() ↳ Retry logic built-in (lkvip-webhook-retry worker for failed outbound)
API Response Envelope
// Success { "success": true, "data": T, "message"?: string } // Error { "success": false, "error": { "code": string, "message": string } }

Security Layers
