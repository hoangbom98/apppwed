1. Tổng Quan Dự Án

CoinBank là nền tảng crypto exchange / ví điện tử với đầy đủ trang marketing (landing pages), luồng xác thực (local + OAuth Google/Facebook), dashboard quản lý tài sản, kết nối ví Web3 (MetaMask, Coinbase…) và trang cài đặt người dùng.

Hạng mụcChi tiết
Cấu trúcMonorepo 2 sub-app: backend/ + frontend/ — không dùng Turborepo hay pnpm workspaces
DBMongoDB (mongoose 8) — 1 collection chính: User, database name: coinbank
AuthJWT dual-token (accessToken + refreshToken) qua HTTP-only cookie, + Passport Google OAuth2, Passport Facebook
EmailNodemailer → Mailtrap (dev) / Gmail OAuth2 (prod)
StorageCloudinary cho avatar
Web3Wagmi 2 + RainbowKit 2 — Mainnet, Polygon, Optimism, Arbitrum, Base, Sepolia
ValidationZod (cả backend lẫn frontend)
OTP / 2FASpeakeasy TOTP cho email verification

5. Vấn Đề Cần Sửa

🔴 Critical (phải sửa trước khi production)

🔴
Chỉ dùng 1 JWT secret cho cả accessToken và refreshToken
signToken() dùng config.JWT.secret cho cả hai loại token. Nếu attacker lấy được 1 token có thể forge token kia. Cần 2 secret riêng: JWT_ACCESS_SECRET và JWT_REFRESH_SECRET.
🔴
URL endpoint sai: /auth/auth/password
Route trong auth.route.ts: router.patch("/auth/password", ...) được mount tại /api/v1/auth → thực tế là /api/v1/auth/auth/password. Frontend AuthService.updatePassword() gọi /password → sẽ 404.
🔴
deleteUser() dùng findOneAndDelete(res.locals.user._id) sai tham số
Thiếu { _id: ... } — mongoose findOneAndDelete nhận filter object, không phải giá trị trực tiếp. Không thực sự xoá user nào cả.
🔴
Wagmi config dùng placeholder transport URLs
wagmi.config.ts có http("https://mainnet.example.com") và https://sepolia.example.com — đây là URL giả, Web3 sẽ không kết nối được. Cần thay bằng Alchemy/Infura/Ankr RPC URL thật.
🔴
WagmiConnect projectId bị hardcode public
wagmi.config.ts: projectId: "8e314179b4d0f35c2c5d3b80085fb549" — WalletConnect projectId hardcode trong source code. Phải đưa vào ENV NEXT_PUBLIC_WALLETCONNECT_PROJECT_ID.
🔴
forgotPassword không gửi email reset link thật
auth.controller.ts line ~80: sendMail({ html: "", subject: "" }) — body email trống. Link reset không được gửi đến user, chỉ trả về token trong response.

🟡 Cần Cải Thiện

🟡
Không có rate limiting
express-rate-limit đã được cài trong dependencies nhưng không được dùng trong app.ts. Endpoints /auth/login, /auth/register, /auth/forgot-password không có giới hạn request — dễ bị brute force.
🟡
helmet() và express-mongo-sanitize không được dùng
Cả helmet và express-mongo-sanitize đã install nhưng không có trong app.ts. Thiếu bảo vệ HTTP headers và NoSQL injection sanitization.
🟡
generateEmailVerificationToken() gửi đến "random@gmail.com" hardcode
Trong auth.controller.ts: to: "random@gmail.com" thay vì gửi đến email của user. OTP sẽ không bao giờ đến đúng người dùng.
🟡
Middleware bảo vệ route: gọi API từ Edge Runtime có thể chậm
middleware.ts dùng axios.get('/api/v1/user') trên mỗi request vào /dashboard — một DB query cho mỗi navigation. Nên decode JWT trực tiếp trong middleware thay vì gọi API.
🟡
Không có refresh token rotation và revocation
refreshToken không được lưu trong DB hoặc Redis — không thể logout thực sự (invalidate token), không thể revoke sau khi bị đánh cắp. Cần lưu token hash vào DB hoặc Redis với TTL.
🟡
Không có endpoint logout
Không có POST /auth/logout để xoá cookies phía server. Hiện tại user chỉ có thể "logout" bằng cách tự xoá cookie phía client.
🟡
Frontend schema và backend schema bị duplicate
Có frontend/src/schema/user-schema.ts và backend/src/schema/user.schema.ts — cùng define các Zod schema giống nhau nhưng tách biệt. Nên tạo shared schema package hoặc dùng monorepo workspace.

🔵 Gợi Ý Cải Thiện

🔵
Chưa có test nào
Cả backend và frontend đều không có file test. Script "test": "echo Error: no test specified". Nên thêm unit tests cho auth.controller, user.model, và integration tests cho auth flow.
🔵
Dashboard pages chủ yếu là placeholder
Các trang prices, portfolios, wallet, cards, accounts trong dashboard chưa kết nối dữ liệu thật — hiện chỉ là UI shell. Cần tích hợp CoinGecko/Binance API cho giá crypto.
🔵
Thiếu pnpm workspace / Turborepo
Backend và Frontend là 2 app riêng biệt trong cùng repo nhưng không có workspace setup — không chia sẻ được types, không chạy build song song được. Nên thêm pnpm-workspace.yaml và package @coinbank/shared.

Các việc ưu tiên cao nhất để production-ready

  1. Sửa forgotPassword: gửi email reset link thật với HTML body đúng
  2. Sửa generateEmailVerificationToken: gửi OTP đến user.email thật, không phải hardcode
  3. Sửa route /auth/auth/password → /password
  4. Sửa deleteUser(): dùng findOneAndDelete({ _id: res.locals.user._id })
  5. Thêm helmet() và express-mongo-sanitize() vào app.ts
  6. Thêm rate limiting cho auth endpoints
  7. Tạo 2 JWT secret riêng (access + refresh)
  8. Thêm POST /auth/logout clear cookies
  9. Thay Wagmi transport URLs bằng RPC thật (Alchemy/Infura)
  10. Đưa WalletConnect projectId vào ENV
